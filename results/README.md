# Results

This folder contains selected results and visualizations generated during the training and evaluation of the Physics-Informed Neural Network (PINN) developed for the core neutronics modeling project.

## Contents

### Training Loss

Visualization of the model's training behavior over the training epochs, showing the variation of the loss during optimization.

### Prediction vs Actual

Comparison between the PINN predictions and the corresponding reference values for the target neutronics variables.

### Physics Loss

Visualization of the physics-based component of the PINN loss, demonstrating how the model incorporates the governing physical constraints during training.

## Purpose

These results provide a visual assessment of the model's training behavior, prediction performance, and adherence to the underlying physical constraints.

## Data Availability

The original IGCAR training dataset is not included in this repository due to institutional and data-sharing restrictions. The figures presented here are derived from the project experiments and are included only where permitted for public sharing.

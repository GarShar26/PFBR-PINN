# Project Documentation

This folder contains documentation related to the Physics-Informed Neural Network (PINN) project developed during the IGCAR internship.

## Project

**Development of a Physics-Informed Neural Network (PINN) Model for Core Neutronics in the Context of PFBR Operator Training Simulator**

The project explores the application of deep learning and physics-informed neural networks for modeling core neutronics behavior.

## Contents

- Project methodology
- PINN formulation
- Model architecture
- Training methodology
- Validation and results
- Technical observations

## Note on Data

The original training dataset is not included in this repository due to institutional and data-sharing restrictions.

The repository therefore focuses on the implementation, methodology, and experimental results that can be publicly shared.
